# Background music on a selling live

Put tracks in `data/music/` (or use **Live tools -> Background music -> Add a track**), tag each one with its licence, press Save.
The overlay page (`http://127.0.0.1:8081/overlay`, the same browser source as the giveaway panel) plays them softly and dips while the host speaks.

| Licence | Played? | Notes |
|---|---|---|
| CC0 / public domain | yes | no conditions |
| I made it / I bought a licence | yes | keep the receipt |
| Pixabay licence | yes | commercial use ok; read the track page; never register the track with a copyright-claim system |
| Mixkit free licence | yes | commercial use, no credit |
| CC BY 4.0 | yes, with credit | artist required; the credit is shown on the overlay while it plays, and "Copy credits" gives you text for the live description |
| CC BY-SA, CC BY-NC | **no** | a shop live is commercial use |
| YouTube Audio Library | **no** | licensed for YouTube, not guaranteed on TikTok |
| unknown | **no** | pick a licence first |

Never use songs from TikTok's sound library, Spotify, YouTube or a "no copyright" claim on a random upload: the label, not the uploader, decides.
Licences change - re-read the track's page when you download it, and keep a screenshot.
